SOSO Desk

A one-person on-chain finance copilot. It reads SoSoValue market snapshots, ETF flows and hot news, then produces ranked, explainable signals with risk controls — position-size caps, a two-input confirmation rule, and a hard NO-TRADE state when inputs conflict. Read-only decision support: it never moves funds, never holds keys, never trades.

    How the signal is built

    The math is shown on every signal card. No black box, no model calls in the shipped app.

    ETF flows (50%)Total daily net inflow across the asset's ETFs. ±$500M maps to ±100.
    Market momentum (30%)24h price change. ±5% maps to ±100.
    News sentiment (20%)Keyword lexicon over headlines: (bullish − bearish) / scored. −1…1 maps to −100…100.
    Confirmation ruleA directional call needs ≥ 2 of 3 components agreeing in sign. Otherwise WAIT.
    Conflict detectionIf any component ≥ 25 points against the total while |strength| < 40, the call is DIVERGENT — size 0, no trade.
    Position capProfile max (2% / 5% / 10%) scaled by |strength| / 100. Zero unless the call is confirmed.

    Data provenance & pipeline

    Air-gapped data pipeline: a scheduled GitHub Actions workflow runs fetch-data.mjs with the SoSoValue key stored as a repo secret (SOSO_API_KEY — never in the repo, never in the browser). It writes data/snapshot.json, and this static page reads that file. That keeps the demo up 100% of the time, prevents key leakage, and makes the signal engine deterministically testable (node test-engine.mjs, 26 checks).

    Known limitation (environmental, not missing integration): from some networks, Cloudflare's edge blocks the SoSoValue /market-snapshot, /etfs and /news/hot paths even with a valid key (verified 24 Nov 2026 from the build VM). /news and /currencies work from anywhere. The fetcher retries every endpoint on every run and labels each section LIVE / SAMPLE / STALE / FAILED, so the dashboard never presents stale or sample numbers as live. If the Actions runner also hits the block, market and ETF sections stay on the checked-in sample and say so.

    Sources: SoSoValue API docs · AKINDO SoSoValue Wave 3 · GitHub repo

    SOSO Desk is decision support, not financial advice. It never executes trades, holds funds, or asks for a wallet.
